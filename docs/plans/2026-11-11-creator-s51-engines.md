# S5.1 多引擎创作与九套母版

## 实施决定

复用 generatedOfflineV1 的不透明 iframe、原生资源 scheme、外部 WebContent 监督、不可变修订及发布注册表。新引擎由原生把核心源码封装为 HTML，仍保持四文件包；旧 S0/S1/HTML 字节合同不变。模型直接输出 GLSL/JavaScript，不输出转义 JSON 源码。精调模板继续可用。

与每个壁纸自行携带 Three.js 相比，固定版本的本地共享运行时减少包体与重复上下文；与开放模块解析相比，精确 URL 白名单保持离线边界。内置 Three.js r180 的许可、来源、输入与输出摘要随代码保留。CSP 仅新增 wm-lib: 脚本来源，connect-src 仍为 none；其他远程资源、存储、下载和原生权限不开放。

参数元数据为版本化 JSON：最多 16 项 number/boolean/color，合法标识符、有限范围、严格默认值与颜色校验。参数更新先只作用于预览；验证后生成新修订才可保存/应用。宿主总线只在活跃渲染订阅时调度，30 FPS 与 2,073,600 像素上限保持；暂停、隐藏与停止释放任务。

shader-glsl 支持 Image 与可选 BufferA 的 ping-pong 反馈，标准 Shadertoy uniforms、ACES/抖动、上下文恢复和有界行号诊断。three-3d 提供本地 RoomEnvironment/PMREM、透视相机、指针阻尼、Bloom 与释放路径。html-canvas 保留自由 HTML。hybrid-image、scene-25d、audio-reactive 仅声明未来阶段，不作为可用功能展示。

## 原子提交

1. 离线库、WallpaperHost、严格 @param 与动态检查器，定向校验安全和属性派生。
2. 两套引擎、核心源码合同、编译行号诊断和非空/非有限帧探针，真实离屏 WebKit 回归。
3. 三引擎各三套完整母版、画廊、自然语言参考匹配、六语言与可视化检查。母版应有真实几何/着色器/模拟，不用静态占位图冒充效果。
4. 安全/解析/九套渲染/修改/恢复覆盖、文档、完整门禁，再构建 macOS 15+ arm64 Ad-hoc 预发布并核对下载摘要。

## 验证与边界

只使用 Mock 模型、内存凭据与离屏渲染，不启动正式版、不改变桌面或个人数据。离屏输出用于视觉审查与参数/比例回归，不等同于多屏、睡眠、真实显示器能耗或商业审美的用户验收。所有失败真实记录；不以跳过、降低断言或占位渲染换取通过。资源/帧率预算限制保持显式且可测。

## 第一阶段结果

已实现离线库、宿主总线、严格参数元数据与动态检查器。28 项宿主/隔离/生成/旧模板定向检查和 17 项参数派生/工程检查通过；脚本完整性 3 项、许可 44 项、本地化 8 项与文档 11 项通过。初次编译修正了异步 XCTest 断言；WebKit 内容规则改用逐 URL 规则；离屏 rAF 改以确定性时钟验证；修订测试按现有草稿→封闭双节点祖先链校正。完整常规门禁留在第四阶段。
