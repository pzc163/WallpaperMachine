# Creator 长生成、连接测试与校验诊断实施计划

**Goal:** 让持续输出的长生成请求正常完成，让连接测试入口始终可见，并提供能定位和修复错误的脱敏诊断。

**Architecture:** Profile 增加可选超时策略和 Kimi 推理强度，保持旧 Codable 记录字节兼容；共享传输层分别监督首响应、首内容、空闲和总时限。诊断由原生结构化类型统一贯穿采集、修复提示与界面，不放宽离线策略、资源上限或发布校验。

**Tech Stack:** Swift 6、URLSession/SSE、SwiftUI/AppKit、WebKit/JavaScriptCore、XCTest、本地 URLProtocol 与内存凭据桩。

## 1. 长生成与 Kimi（原子提交一）

- 修改 `App/Services/LLM/ProviderProfile.swift`，新增可选配置；新建 `LLMTimeoutPolicy.swift` 与计时证据类型，旧记录缺省字段继续不编码。
- 云端默认：首响应 60 秒、首有效内容 180 秒、空闲 120 秒、总时限 1200 秒。本地默认：300/600/300/3600 秒。界面允许独立调整，总时限有界，最多 7200 秒。
- `LLMStreamOperation` 同步配置 URLSession 与原生计时器；任何数据刷新空闲，只有实际思考/正文刷新内容状态。SSE 心跳不能无限掩盖首内容未到。取消立即结束等待；总时限仍为最终保护。
- 只对支持的 Kimi K3 模型发送顶层 `reasoning_effort`，提供 low/high/max，缺省 low；不对其他模型发送该字段，不使用 K2 的关闭思考参数。
- 精确区分首响应、首内容、空闲、总时限与服务端超时；记录有界耗时/最后数据间隔，不记录端点/密钥。超时、断网及截断不触发代码自动修复，实际请求预算仍逐次计数。
- 进度分别显示等待/思考/正文；思考计时从实际思考片段开始，接收字符不冒充 token。
- 测试：`LLMStreamingUXTests`、新增长生成/策略合同测试、Provider/Profile/Repair 回归；向纯状态机提供单调时间戳模拟小时级等待，并运行短时 Mock，不发起真实模型请求。

## 2. 连接测试入口（原子提交二）

- `CreatorProviderConnectionForm` 始终显示测试入口。未保存或修改过的配置使用“保存并测试”，已保存且无变更使用“测试连接”；配置无效时禁用并提示原因。
- 通过 PanelController 类型化操作顺序保存并测试，保留目标确认、配置代次与凭据绑定；不测试旧表单值，不把空密钥复制至其他连接。成功、失败和取消均更新当前连接状态。
- 云端/本地一致，获取模型列表仍为独立操作。六语言与离屏宽窄布局、取消和陈旧配置测试覆盖。

## 3. 可定位诊断（原子提交三）

- `CreatorRepairIssue` 增加可选结构化诊断：阶段、稳定错误码、相对源码位置、有限的安全消息/上下文与超时证据。历史记录兼容，任意原始错误字符串不能直接进入日志。
- HTML/JS 采集语法、运行和未处理 Promise 错误；宿主注入不改变作者行号。GLSL 保留 pass 与相对行号，并给出可理解的错误解释；无法定位明确显示未知，不猜测位置。
- 页面无响应、进程退出、资源策略拒绝、无有效像素与封面失败分别报告。保持已有外部监督和完整校验，不以延长网络时限放宽沙箱。
- 报告提供中文摘要、位置跳转、相关源码、修复提示及复制脱敏报告；模型修复使用相同结构化证据。失败源码可单独再次验证，不重复调用模型，旧有效版本不受影响。
- 回归：JS/Shader 行号映射、敏感数据清洗、旧诊断读取、运行失败修复、源码重验、报告六语言与宽窄布局；不启动可见应用或切换桌面。

## 4. 门禁与交付

- 各阶段先跑定向测试，源码完成后执行一次 `python3 scripts/test.py` 完整门禁；失败才重跑。补齐六语言、文档/链接检查及验收记录。
- 门禁通过后按上述目的分三次提交；共享文件用暂存补丁拆分，不提交测试产物或个人配置。仅推送 `feat/ai-creator`。
- 构建 Release；在临时副本中使用经 SHA-256/ABI/导出符号验证的同版本 macOS 15 官方依赖打包，校验签名、DMG 挂载与最低系统版本。
- 新建独立 GitHub Pre-release，显式 `--prerelease --latest=false`，回下载核对 SHA-256；不修改 main、正式 latest 或本机正式版。清理本轮临时产物，保留构建应用。

## 实施与验证结果（2026-11-12）

- 三项修复与 Kimi 设置已实现，新增 19 项原生回归。最终整合定向测试 93 passed，0 failed；文档/六语言检查 28 passed。
- 完整 `python3 scripts/test.py`：724 项 Python 测试通过；原生 5140 passed、0 failed、69 skipped。Live LLM、Benchmark、Soak 与外网 opt-in 均未开启。
- 完整门禁的 3 条主线程运行警告来自未修改的 AppUpdate、LockScreenWebMPlayer、WebMFilteredVideoSink 测试，非本轮 Creator 测试失败。
- 小时级等待通过单调时间戳状态机验证，并以短时真实 URLSession/Mock 验证分段超时和取消；未重新执行真实付费模型长生成或物理显示器验收。
- 实际离屏 WebKit 覆盖 JS 静态语法行号、rAF 异常、Promise 拒绝、资源分类、黑帧/透明帧，以及旧有效修订保留。WebKit 隐藏顶层异常类型/位置时诚实显示不可用；复制诊断不含源码或原始错误正文。
- macOS 15+ 发布继续使用同版本官方 arm64_sequoia 依赖及 Ad-hoc 签名；部署版本、ABI/导出符号、签名和挂载检查属于打包门禁，不替代 macOS 15 真机验收。
