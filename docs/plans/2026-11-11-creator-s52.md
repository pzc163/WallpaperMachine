# S5.2 — 供应商中心、单舞台和离线图影创作

状态：实施中。范围为 `feat/ai-creator`，保持 macOS 15+、Ad-hoc 预发布，不修改主分支和正式应用。

## 交付顺序

1. 供应商中心：11 家云端预设、LM Studio/Ollama、本地与云端自定义入口；一份 Profile 管理一把密钥与多个模型。离线 LobeHub 图标附锁定版本、来源和 MIT 许可证。自动上下文/输出为默认，高级 JSON 选项折叠。
2. 单舞台：主舞台承载渲染、源码编辑、比例与预览控制；检查器保留参数/历史以及固定发布按钮；对话抽屉。新增半浮点线性采样运行库版本，保留旧运行库字节。参数严格校验后热更新，保存时自动封闭新修订；源码编辑必须完整重新验证。
3. 图影资源：工程内有界素材、离线 `wm-media://` Range 服务、原生图像/视频首帧分析、图影混合与 2.5D 引擎及六套母版；版本化工程分享包。
4. 定向测试、完整常规门禁、Release 构建与独立 GitHub Pre-release。

## 不可变边界

- Provider Profile 的身份、origin 和配置代次继续约束凭据。模型选择独立于配置修改；只能选择该 Profile 已启用的模型。UI 不读取 Keychain，本地空 Key 不访问 Keychain。
- 新增可选 Codable 字段，旧记录不凭空增加字段；v1/v2 包和运行库的黄金字节摘要保持不变。
- 媒体包采用新的封闭版本，清单覆盖每个素材的相对路径、类型、字节与摘要；拒绝链接、目录穿越、未知文件、超限内容以及修改后仍引用旧验证证据。
- `wm-media://` 只能访问当前已验证包内授权素材，支持单段 Byte-Range 和取消；不允许任意文件读取、远程资源或 Base64 壁纸媒体。
- 素材分析仅在导入时进行。视觉模型缩略图为用户明确选择的单次上传，默认关闭；不发送本地路径或整个素材文件。
- 参数调整不要求用户再次点击验证按钮；原生参数域检查、不可变派生与封面/摘要更新仍由保存事务完成，不能将旧报告绑定到不同字节。源码编辑始终执行完整静态和离屏运行检查。
- 图影动态仍受 30 FPS、像素上限、遮挡暂停、离线 CSP 和宿主 watchdog 约束。半浮点缓冲属于用户要求的渲染精度升级，限定同一画布像素上限并提供受检回退，不增加无界缓存。

## 验证与发布

使用临时存储、内存凭据、Mock HTTP 和离屏 WebKit；不访问真实模型服务或个人 Keychain，不启动可见应用，不修改桌面。

定向覆盖：多模型凭据复用与失效、预设/图标资源、上下文边界、源码编辑失败保留旧版、参数热更新、包清单/路径/Range/取消、图像与视频导入、分享包篡改、两引擎非空帧和半浮点回退。完整门禁为 `python3 scripts/test.py`；Release 构建为 `python3 scripts/build.py --swift-only --configuration Release`。

实机外部模型兼容性、macOS 本地网络授权、真实多屏能耗和可见 UI 观感保留人工验收口径，不以 Mock 或离屏测试代替。
