# S5.2 离线图影创作

[实施计划](../plans/2026-11-11-creator-s52.md) · [引擎合同](creator-engines.md)

## 使用流程

从创作舱的「上传图片/视频」、文件拖入舞台/输入框、粘贴图片或「从现有壁纸库选择底图」导入。原文件保持不变；素材复制到当前工程的不可变修订中。没有工程时自动建立工程，图片默认进入雨夜玻璃母版，视频进入氛围时钟母版。已有图影引擎保留当前源码和参数，替换素材后重新验证。

右侧控制填充/适应/拉伸、曝光（-2…1 EV）和视频倍速（0.25…2）。这些原生参数支持热更新并直接保存新修订；原始源码编辑仍必须通过运行验证。保存入库与应用到显示器是独立动作。

支持 PNG/JPEG/WebP/HEIC 图片，以及 MP4/MOV/M4V/WebM 视频。图片会去除 EXIF/GPS 并归一化为最长边 2048 的 JPEG；视频保持原始容器，必须由当前系统支持其编码。单素材最多 64 MiB、包内素材合计 128 MiB，视频最长 600 秒、编码尺寸最长边 4096。WebM 首帧使用内置解码器；实际播放还需通过本机 WebKit 运行验证，扩展名并不保证任意编码都可播放。

## 包格式与离线协议

媒体使用 `bundleVersion: 3`：四个原有文件加 `assets/`，清单固定 base、mask、thumbnail 的 SHA-256、真实字节数、类型和相对路径。路径只能是 `assets/<sha256>.<extension>`；禁止链接、目录穿越、未知文件、跨包访问和超限内容。v1/v2 没有媒体时保持旧字节重建。验证报告和发布注册表覆盖所有媒体字节；修改任意素材使旧报告失效。

`wm-media://bundle/assets/...` 仅映射当前冻结包。处理器支持 GET、HEAD、单段 Range（206/416、后缀、开放尾部）、64 KiB 分块和取消；并发上限 4。CSP 只对 img-src/media-src 增加 wm-media，connect-src 仍为 none；handler 不解析本地绝对路径、不联网、不创建 Base64 媒体 URL。脚本仍由 wm-lib 精确白名单提供。图片/视频可用 CORS 匿名方式作为 WebGL 纹理。

离屏视频验证使用从不 orderFront、不可成为 key/main 的临时媒体宿主窗口，提供 WebKit 的页面媒体启动条件。它不显示窗口、不捕获桌面、不控制正式版；在成功、异常和取消时均释放。普通图片/代码保持无窗口离屏验证。正式预览与桌面使用各自真实窗口，遮挡暂停由原有宿主管理。

## 原生分析与视觉模型

导入时通过 ImageIO/CoreImage（视频首帧由 AVFoundation/内置 WebM 解码）计算五色调色板和 512px 亮度遮罩。`uLumaMask` 是亮度，不是 AI 深度；不会伪称完成图层分割或遮挡补全。分析只在导入时执行。

模型默认只收到种类、尺寸、调色板和引擎合同。先在 Provider 的对应模型启用视觉能力，再为单次任务勾选发送缩略图；发送后开关复位。三协议分别使用其图片字段，只上传不超过 512px/256 KiB 的去元数据 JPEG，不包含路径、原视频或整个工程。素材不依赖模型服务即可本地播放。

## 两种引擎和六套母版

两种引擎均由原生重建 WebGL2 外壳，提供 uBaseTexture、uLumaMask、uMediaResolution、wmBase/ wmLuma 取样函数和固定范围的 mediaFill/mediaExposure/mediaSpeed 参数。继续执行 30 FPS、2,073,600 像素上限、RGBA16F/受检 RGBA8 回退、ACES/抖动、上下文恢复与外部 watchdog。

| 引擎 | 母版 | 机制 |
| --- | --- | --- |
| hybrid-media | Nocturne Glass | 分层雨滴、像素折射、指针擦拭玻璃 |
| scene-2d | Painted Horizons | 亮度与高度分层的采样视差、前中远景雾化 |
| hybrid-media | Crepuscular Light | 有界亮度取样、晨昏光束与浮尘 |
| hybrid-media | Stillwater | 局部倒影、水线遮罩与细波扰动 |
| scene-2d | Lucent Grove | 分层萤火、指针视差与暗光薄雾 |
| scene-2d | Ambient Cinema | 视频/图片氛围光、静音循环和原生字体时钟 |

2.5D 使用亮度/高度驱动的有限层合成，不执行无依据的单图真实几何重建。无上传素材时使用应用内三张原创默认底图，详见[素材来源](../../App/Resources/CreatorMedia/README.md)。真实截图由原生 WebKit 验证生成。

## 工程分享

`.wmpkg` 为版本化二进制封装（WMPKG001 + 有界规范 JSON 目录 + 原始文件字节），不是 ZIP 或 JSON/Base64 大字符串。最多 129 MiB；路径、长度、摘要、尾部数据均严格检查。仅导出当前已验证修订及素材；不包含对话、Provider、Keychain、个人路径或旧验证报告。导入新建工程 ID，重新执行静态与真实运行检查，视频另有原生解码预检。原工程及不可变历史保持不变。

## 验证口径

常规自动化使用生成的视频、内存 Mock、临时存储和离屏 WebKit；不请求付费模型、不读取个人钥匙串、不应用真实桌面。macOS 15/不同 GPU 的实际视频编码支持、可见交互和多屏能耗须在预发布包上人工验收。
